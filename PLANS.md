# Project Plan

## Summary

Deliver a CLI-first daily LinkedIn job indexer using public guest HTML endpoints, SQLite deduplication, deterministic keyword filtering, CSV/JSON output, automated tests, CI, and a scheduled GitHub Actions run.

## Milestones

- [x] Establish package, configuration, and domain interfaces.
- [x] Implement and test LinkedIn HTML parsing and HTTP failure detection.
- [x] Implement and test filtering, persistence, and end-to-end orchestration.
- [x] Add CLI, documentation, CI, daily workflow, and package validation.
- [x] Push the feature branch and open a PR with the system DAG.
